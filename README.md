## Принцип безопасного вывода данных

Для вывода пользовательских данных и данных, которые могут прийти из формы, `localStorage`
или API, используется `textContent`, а не `innerHTML`. `innerHTML` разбирает строку как
HTML-разметку: если в данных окажется, например, `<img src=x onerror=alert(1)>`, браузер
создаст элемент и выполнит код. `textContent` выводит ту же строку как обычный текст.
