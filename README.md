## Основа проекта

Проект создан на основе адаптивной версии интернет-магазина из контрольной работы №3
(`kr3-responsive-shop`). Из КР №3 перенесены все страницы, стили `style.css` и
`responsive.css`, изображения, бургер-меню и модальное окно. В КР №4 магазин стал
интерактивным: карточки, список товаров в форме заказа, страница товара и корзина
строятся JavaScript из одного массива данных.

## Как запустить

1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере (двойной щелчок) или запустить Live Server в VS Code.
3. Для проверки открыть DevTools → Console: ошибок быть не должно.

Сервер и сборка не нужны: используется чистый JavaScript без библиотек.

## JavaScript-файлы

Все скрипты подключаются в `<head>` с атрибутом `defer`: они загружаются параллельно
с HTML и выполняются по порядку после разбора страницы. Поэтому `data.js` всегда
подключается первым — остальные файлы используют массив `products`. На каждой странице
подключены только нужные файлы, а код проверяет, есть ли нужный элемент
(`if (productsContainer) { ... }`), поэтому на других страницах ошибок нет.

| Файл | За что отвечает | Где подключён |
|---|---|---|
| `data.js` | массив `products` и объект `categoryNames` | все страницы |
| `storage.js` | `loadFromStorage`, `saveToStorage`, `removeFromStorage` с `try...catch` | все страницы |
| `utils.js` | `formatPrice`, `calculateDiscount`, `calculateFinalPrice`, `getFinalPrice`, `getProductStatus`, `getCategoryName`, `findProductById`, `createElement`, `createProductImage` | все страницы |
| `favorites.js` | состояние избранного, кнопка-сердечко, раздел «Избранное» в корзине | главная, каталог, товар, корзина |
| `cart.js` | состояние корзины, `addToCart`, `removeFromCart`, `changeQuantity`, расчёт суммы через `reduce`, промокоды, счётчик в шапке, страница корзины | все страницы |
| `catalog.js` | поиск, фильтр, сортировка, `createProductCard`, `renderProducts`, `updateCatalog`, пустое состояние, статистика | главная, каталог, товар, корзина |

## Массив товаров

В `js/data.js` хранится массив `products` из **10 товаров** четырёх категорий:
мыши (`mouse`), клавиатуры (`keyboard`), наушники (`headphones`), микрофоны (`microphone`).
Значения категорий совпадают со значениями `<option>` в фильтре каталога.

У всех товаров одинаковая структура:

```js
{
  id: 9,                          // уникальный идентификатор
  title: 'Наушники HyperX Cloud II',
  category: 'headphones',         // совпадает с value в фильтре
  price: 8990,                    // число, а не строка
  discountPercent: 15,            // скидка в процентах (0 — без скидки)
  rating: 4.8,
  isAvailable: true,              // есть ли товар в наличии
  isPopular: true,                // метка «Хит» и вывод на главной
  image: 'hyperx-cloud-ii',       // начало имени файла: images/hyperx-cloud-ii-640.webp
  imageWidth: 640,
  imageHeight: 480,
  alt: '...',                     // описание изображения
  description: '...',
  connection: 'USB / 3,5 мм',     // для таблицы сравнения
  feature: 'Виртуальный звук 7.1',
  specs: [{ name: 'Тип', value: 'Проводная гарнитура' }, ...]
}
```

Два товара отсутствуют в наличии (Fifine AM8T и ARDOR GAMING Dreamy), у двух есть скидка
(Logitech G304 — 10%, HyperX Cloud II — 15%).

## Реализованные функции

### Генерация карточек

Карточки не написаны в HTML, их создаёт функция `createProductCard(product, options)`
в `catalog.js`: элементы создаются через `document.createElement()` (обёртка
`createElement(tag, className, text)` из `utils.js`), текст записывается через
`textContent`, классы — через `className` / `classList`, готовые элементы добавляются
через `append`. Функция `renderProducts(container, products)` очищает контейнер
(`container.textContent = ''`) и выводит карточки заново. Та же функция выводит
популярные товары на главной, похожие товары на странице товара и избранное в корзине.

### Поиск

`searchProducts(products, query)` — поиск по названию без учёта регистра: строка
обрезается `trim()`, приводится к нижнему регистру и проверяется через `includes()`.
Поиск реагирует на событие `input`: список обновляется при вводе каждого символа.

### Фильтрация

`filterProductsByCategory(products, category)` — значение `all` возвращает все товары,
иначе `filter()` оставляет товары нужной категории. Фильтр реагирует на событие
`change`. Дополнительно есть флажок «Только в наличии» (`getAvailableProducts`).

### Сортировка

`sortProducts(products, sortType)`: по умолчанию, сначала дешевле, сначала дороже,
по названию А–Я (`localeCompare`), по рейтингу. Сортируется **копия** массива
(`[...products]`), потому что `sort()` меняет исходный массив. Цена сравнивается с
учётом скидки — в том виде, в котором она показана на карточке.

### Общая логика каталога

Выбранные условия хранятся в объекте `catalogState`. Любой обработчик меняет
состояние и вызывает `updateCatalog()`, которая применяет
`getPreparedProducts(products, catalogState)` (поиск → наличие → категория →
сортировка), выводит карточки, количество найденных товаров и пустое состояние.

### Валидация форм

`validation.js` проверяет формы заказа, быстрой заявки и обратной связи. Для каждого
имени поля есть функция проверки (объект `fieldValidators`):

- имя — не короче 2 символов, только буквы, пробел и дефис;
- e-mail — по регулярному выражению `^[^\s@]+@[^\s@]+\.[^\s@]+$`;
- телефон — 11 цифр, первая 7 или 8;
- товар, способ получения, тема — выбран вариант списка;
- количество — целое число от 1 до 10;
- адрес — обязателен только при курьерской доставке;
- дата связи — не раньше сегодняшнего дня;
- сообщение — не короче 10 символов;
- согласие на обработку данных — флажок отмечен.

Отправка отменяется через `event.preventDefault()`. Ошибка выводится под полем
через `textContent`, у поля ставится `aria-invalid="true"`, текст ошибки связан с полем
через `aria-describedby`, фокус переходит на первое неверное поле, над кнопками
появляется общее сообщение «Проверьте поля формы: ошибок — N». Поле с ошибкой
проверяется заново при вводе, и ошибка исчезает сразу после исправления.
`alert()` в проекте не используется.

### Безопасный вывод данных

Все данные — названия товаров, описания, введённый в поиск текст, значения из
`localStorage` — выводятся через `textContent` или атрибуты элементов, `innerHTML` в
проекте не используется. `innerHTML` разбирает строку как HTML: строка
`<img src=x onerror=alert(1)>` превратилась бы в элемент и выполнила код. `textContent`
выводит её как обычный текст. Данные из `localStorage` дополнительно проверяются:
испорченный JSON перехватывается `try...catch`, записи корзины с несуществующим `id`
или неверным количеством отбрасываются, а цена всегда берётся из `data.js`.

## Самостоятельные доработки

1. **Корзина** (`cart.html`, `cart.js`) — добавление из каталога, главной, страницы
   товара и избранного, изменение количества кнопками «−» / «+» и вводом числа
   (от 1 до 10), удаление товара, очистка корзины, пустое состояние со ссылкой в каталог.
2. **Расчёт суммы через `reduce`** — количество товаров (`getCartItemsCount`) и сумма
   (`calculateCartTotal`); в шапке на всех страницах счётчик товаров в корзине.
3. **Промокоды** — `DEVICE10` (скидка 10%) и `STUDENT500` (500 ₽ на заказ от 5 000 ₽);
   скидка пересчитывается при изменении корзины, неверный код даёт сообщение об ошибке.
4. **Сохранение в `localStorage`** — корзина, промокод, избранное и выбранная тема
   сохраняются между перезагрузками; корзина синхронизируется между вкладками
   (событие `storage`).
5. **Избранное** — кнопка-сердечко на карточках (`aria-pressed`), раздел «Избранное» в
   корзине с возможностью сразу добавить товар в корзину.
6. **Тёмная тема** — кнопка в шапке; по умолчанию тема берётся из настроек системы,
   выбор сохраняется, тема применяется до отрисовки страницы (без мигания).
7. **Страница товара по `id`** — `product.html?id=9` показывает один товар,
   похожие товары той же категории и таблицу сравнения с выделенной строкой;
   неверный `id` даёт сообщение «Товар не найден». Без параметра выводятся все товары.
8. **Улучшенная карточка товара** — метки «Хит» и «−15%», старая цена зачёркнута,
   категория и рейтинг, статус наличия, у отсутствующих товаров кнопка отключена.
9. **Расширенное пустое состояние каталога** — пояснение, какие условия мешают
   найти товары, кнопки-подсказки с брендами (нажатие подставляет запрос) и кнопка
   «Сбросить фильтры»; кнопка сброса неактивна, пока фильтры не изменены.
10. **Улучшенная форма заказа** — список товаров строится из массива, предвыбор товара
    по ссылке `order.html?product=5`, заказ сразу всех товаров из корзины с итоговой
    суммой и промокодом, маска телефона `+7 (900) 000-00-00`, имитация отправки
    (кнопка «Отправка…» заблокирована на 1 секунду), после успеха — сообщение с
    составом заказа, очистка формы и корзины.
11. **Уведомления** — короткие сообщения внизу экрана (`showToast`) о добавлении в
    корзину и избранное, сбросе фильтров и смене темы; область `role="status"`
    зачитывается экранными дикторами.
